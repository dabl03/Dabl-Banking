
## Como usar:
Primero debemos descargar desde git:
<pre><code>
	git clone --recurse-submodules https://github.com/dabl03/SimpleServerHTTP
<code><pre>
o
<pre><code>
	git clone https://github.com/dabl03/SimpleServerHTTP
	git submodule update --init --recursive
</code></pre>

## Requisitos:
- Python 
- Dotnet
Los proyectos se usan son:
- https://github.com/dabl03/SimpleServerHTTP : Se usa para crear el servidor.
- https://github.com/dabl03/Banco : Se usa para las operaciones bancarias.
